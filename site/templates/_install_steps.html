What does this command do?

It downloads the newest JBrowser from our official releases on GitHub, checks that the file is exactly the one we published (using its SHA-256 fingerprint), and opens the normal JBrowser installer. It doesn't need administrator rights and changes nothing else on your computer. The script is short and public: read it on GitHub.

Why not a normal download? JBrowser is new, so Windows doesn't recognise it yet and shows a "Windows protected your PC" warning for a downloaded installer. Installing with the command avoids that warning, and it checks the file for you before running it.

Prefer a normal download? Download the installer and open it. If Windows says "Windows protected your PC", click More info, then Run anyway.
