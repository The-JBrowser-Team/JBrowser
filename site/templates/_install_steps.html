Or install with one command (no Windows warning)
  1. 1

    Open PowerShell: press the Windows key, type PowerShell, press Enter.

  2. 2

    Paste this line and press Enter:

irm https://raw.githubusercontent.com/{{repo}}/main/install.ps1 | iex

It downloads JBrowser from our GitHub releases, checks the file's fingerprint and opens the same installer. Read the script.
